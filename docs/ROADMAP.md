# Roadmap — Ultra 2026 (plataforma completa)

## Fase 1 — FUNDAÇÃO (v0.1.0) ✅
Cérebro Ollama offline · plugins auto-descritivos · voz em cadeia (nunca mudo) ·
HUD reativo recolorível · memória persistente · janela deslizante · autoconhecimento.

## Fase 2 — VOZ E PRESENÇA
- Wake word "Ei, Jarvis" local (openwakeword ou alternativa leve)
- Pressione-para-falar global (Ctrl+Espaço)
- Proteção contra autoeco (não responder à própria fala)
- Seletor de microfone/alto-falante por nome
- Painel de memória na UI (ver/apagar o que ele sabe)

## Fase 3 — AVATAR HOLOGRÁFICO
- Cabeça humana animada no HUD, desenhada por software (sem GPU)
- Dublagem real (~50 formas de boca/s a partir dos formantes)
- Atuação facial: sobrancelhas, olhar, piscadas, acenos
- Rosto como status: pensa, ouve, fala, dorme

## Fase 4 — AGENTE
- Planejamento multi-etapas (modo agente com plano JSON)
- Desfazer real (arquivos movidos/criados, configurações)
- Confirmação humana para ações irreversíveis
- Monitoramento em background + resumo matinal + check-ins contextuais

## Fase 5 — PLATAFORMA COMPLETA
- Núcleo vira serviço HTTP local → app web (qualquer dispositivo)
- Painel de controle remoto no celular (pareamento QR)
- Sincronização de sessão entre dispositivos
- Skills extras: busca multimodo, clima, lembretes nativos, controle do sistema

## Princípios invioláveis
1. Offline primeiro — nuvem é opcional, nunca obrigatória
2. Nada falha em silêncio — todo problema é anunciado com motivo
3. Uma skill = um arquivo — sem registro, sem configuração
4. pyflakes limpo antes de qualquer release
